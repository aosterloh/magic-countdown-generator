● ● ● ● EGM Phase E4: Specification v5.0

CountdownMaker: 30-Second Cinematic Video Generator

Gemini Nano Banana Model Grounding, Rotating Prompt Carousel, One-by-One Image Stream, Google Palette & Dark/Light Mode

1. Executive Summary & Objective

CountdownMaker v5.0 elevates the generation experience with Google design ergonomics, dynamic carousel feedback, one-by-one image rendering, and integration with the latest Gemini Nano Banana (NB2 / Gemini 2.0 Flash) multimodal image model.

v5.0 Core Enhancements:
  • Gemini Latest Nano Banana Model: Native image generation & multimodal grounding utilizing Gemini 2.0 Flash / Nano Banana + Imagen 3 endpoints.
  • Rotating Text Prompt Carousel with Giant Number: During synthesis, users view an interactive carousel of the 10 diegetic prompts featuring a prominent, large representation of the active countdown number (10 $\to$ 1). Autoscrolls every 10 seconds with manual swipe/nav controls.
  • Progress Bar Below Carousel: A unified Google-colored progress bar ($0\% \to 100\%$) positioned immediately beneath the carousel.
  • Dynamic One-by-One Image Stream: No empty placeholder slots during generation; images appear dynamically one-by-one as each completes underneath the progress bar.
  • Google Brand Aesthetics & Dark/Light Mode: UI styled with Google Blue (#4285F4), Red (#EA4335), Yellow (#FBBC04), Green (#34A853) and full light/dark theme support.

3. Acceptance Criteria (v5.0)

  1. UI provides a seamless Dark / Light mode toggle with persistent state.
  2. Google brand palette (Blue, Red, Yellow, Green) is harmoniously applied across buttons, badges, and progress meters.
  3. During image generation, a rotating carousel displays the 10 prompts with large countdown numbers and 10s autoscroll.
  4. The progress bar is placed directly below the carousel.
  5. Zero empty placeholder image slots are shown during creation; images appear one by one as they finish.
  6. Model configuration grounds to the latest Gemini Nano Banana / Imagen 3 model.
