1. 🎯 Executive Summary & Purpose

The Magic Countdown Generator is an enterprise generative video system designed to create bespoke, photorealistic 30-second cinematic countdown videos (counting sequentially backwards from 10 down to 1).

The generated videos are tailored dynamically to any customer, brand identity, or industry theme (e.g. Lufthansa, Infineon, Nike, BMW, SpaceX). The countdown numbers are diegetic—meaning they physically exist within the filmed environment (stenciled hangar bay markings, server rack LED units, illuminated cockpit tachometers, chronograph bezels) rather than being synthetic digital overlays.

The final master output is a seamless 16:9 4K UHD video @ 60fps perfectly synchronized with a dramatic 30-second soundtrack (featuring a 1.0-second blackout pause before the bass drop), optimized for keynote openings, YouTube 4K uploads, Google Slides embeds, and 32:9 giant cinema displays.

2. 🎵 The 30-Second Audio Track & Dramatic Structure

Every generated countdown is driven by a single fixed master soundtrack: public/countdown/countdown_track.mp3 (Duration: 30.000s @ 44.1kHz, 320 kbps stereo). The composition follows a classical Hollywood teaser-trailer structure split across two acts and a silence gap:

3. ⏱️ Temporal Math & Video Transformation Logic

Google Veo 3.1 generates raw video clips of exactly 4.000 seconds (240 frames @ 60fps). Because Act 1 slots require 2.300s and Act 2 slots require 3.300s, each clip undergoes temporal transformation.

A. Temporal Transformation Modes

  • TRUNCATE_FRONT (Default & Standard): Trims the opening seconds of the video, keeping the end where the physical numeral is revealed in sharp macro focus.
    Formula: trimStart = 4.000 - targetDuration (Act 1: trim 0.0s–1.7s, keep 1.700s–4.000s; Act 2: trim 0.0s–0.7s, keep 0.700s–4.000s).
  • TRUNCATE_BACK: Keeps the beginning of the shot and trims the end (useful if the number reveal was established upfront).
    Formula: trimStart = 0.000, duration = targetDuration.
  • SPEED_UP: Compresses the entire 4.0s unbroken camera motion smoothly into the target slot duration.
    Formula: setpts=(targetDuration / 4.000) * PTS (Act 1 speed factor = 0.575x; Act 2 speed factor = 0.825x).
  • PASSTHROUGH: Retains full 4.0s duration without speed change (used during solo slot previews).

B. Interactive Playhead Mapping Function (mapPlayheadToSlotTime)

When the user scrubs the 30-second waveform timeline in the UI, the playhead time $T \in [0.0, 30.0]$ is translated in real-time into the exact active slot index, local video clip time, and dramatic silence state: 

if (T >= 9.200 && T < 10.200) {
  // Dramatic Pause: Render 100% Solid Black Screen, Zero Badge Overlays
  return { slotIndex: 0, localClipTime: 0.0, isDramaticPause: true };
} else if (T < 9.200) {
  // Act 1: Slots #10 down to #7 (Duration = 2.300s per slot)
  const slotIndex = 10 - Math.floor(T / 2.300);
  const slotOffset = T % 2.300;
  const localClipTime = (4.000 - 2.300) + slotOffset; // Starts at 1.700s in raw clip
  return { slotIndex, localClipTime, isDramaticPause: false };
} else {
  // Act 2: Slots #6 down to #1 (Duration = 3.300s per slot)
  const act2Time = T - 10.200;
  const slotIndex = 6 - Math.floor(act2Time / 3.300);
  const slotOffset = act2Time % 3.300;
  const localClipTime = (4.000 - 3.300) + slotOffset; // Starts at 0.700s in raw clip
  return { slotIndex: Math.max(1, slotIndex), localClipTime, isDramaticPause: false };
}

4. 🚀 Complete Step-by-Step Studio Workflow

Step 0: Customer Theme & AI Search Brainstormer

User inputs a brand name (e.g. "Lufthansa", "Infineon"). Clicking 🪄 Auto-Brainstorm 10 Scenes invokes gemini-3.8-flash (with gemini-3.7-flash fallback) with Google Search Grounding to research the company's manufacturing, aircraft, chips, or facilities, outputting 10 custom visual concepts mapped across 4 pillars. User can edit the brainstorm text freely.

Step 1: Diegetic Prompt Synthesis & Review

Generates 10 prompt sets based on veo-prompt-guide.md. Features the 2.0s / 2.0s Rule (establishing motion followed by 25%-40% macro lock), strict single-instance numeral enforcement, and no-spawn directives. User can review in carousel, regenerate, or edit prompts inline.

Step 2: Start & End Visual Frame Synthesis

Synthesizes Frame 1 (Start Image) and Frame N (End Hero Reveal Image with embedded number) using Gemini Nano Banana / Imagen 3. User can upload brand logo reference files for image-to-image style anchoring.

Step 3: Veo 3.1 Text-to-Video Engine

Dispatches asynchronous video generation to Vertex AI / AI Studio Veo 3.1. Supports Veo 3.1 Fast (720p 60fps Turbo), Veo 3.1 Full (4K UHD Master), and Veo 3.1 Lite. Includes polling loop, retry fallbacks, and live status progress bars.

Step 4: Interactive Waveform Timeline

WebAudio / WaveSurfer.js timeline visualizer. Shows 30s audio waveform, slot boundaries, play/pause controls, beat drop indicator, and real-time black screen pause rendering between 9.20s and 10.20s.

Step 5: Master Concat & Dual 4K Upscale Export

User opens the Master Export modal and selects between Option 1 (Instant 4K Lanczos Master ~5-8s) or Option 2 (Real-ESRGAN AI Super-Resolution ~2-4m). FFmpeg stitches the clips, inserts the black pause, mixes the 30s audio track, and outputs a 16:9 4K UHD MP4.

5. 🎬 Veo 3 Prompt Engineering & 2-Phase Temporal Reveal Architecture

Prompt synthesis is dynamically driven by veo-prompt-guide.md (which hot-reloads live from disk on every generation request).

A. 2-Phase Temporal Action Architecture (Seconds 0–2 vs Seconds 2–4)

  • Phase 1 (Seconds 0–2 • Establishing & Movement): Wide/medium tracking camera movement across authentic brand facility. Zero visible numerals or text in the initial view.
  • Phase 2 (Seconds 2–4 • Macro Reveal): Camera smoothly pushes in, pans, or unmasks to lock onto the pre-existing physical numeral '[N]' centered in razor-sharp focus in the final seconds.
  • Strict Word Budget: Prompts are kept between 40–55 words to prevent token dilution.

B. Standard 2-Phase Prompt Sentence Structure (Under 55 Words)

Smooth continuous forward camera tracking through [authentic brand environment], establishing ambient movement with zero visible numerals; in seconds 2-4, camera executes a dynamic macro push-in locking directly onto the pre-existing physical numeral '[N]' [material & illumination] centered on [carrier surface] in razor-sharp focus, 35mm anamorphic lens, shallow depth of field, volumetric lighting, photorealistic 8K.

C. 🤖 Veo AI Quality Assistant (Gemini 3.8 Flash Multimodal Frame Inspector)

  • 4-Frame Extraction: FFmpeg automatically extracts 4 sequential keyframes ($t=0.5\text{s}, 1.5\text{s}, 2.5\text{s}, 3.5\text{s}$) upon video completion.
  • Multimodal Inspection: Gemini 3.8 Flash (with 3.7 Flash fallback) grades numeral presence, checks reveal timing, detects duplicates/hallucinations, and gives a score (1–10).
  • 1-Click Self-Improvement: If a numeral is missing or distorted, the Assistant automatically crafts an optimized high-contrast prompt and provides a 🪄 1-Click Apply & Regenerate action.

Project Deletion Guarantee:
When a user deletes a single project (or executes "Delete All Projects"), deleteJobFromGcs(jobId) permanently deletes all objects with prefix jobs/${jobId}/ (including all images, raw videos, processed clips, and master renders) as well as unlinking any cached files in public/output/. Zero orphaned storage remains.

8. 🔒 Security, Authentication & Domain Gate

  • Authorized Domains Gate: Access to video/prompt generation endpoints is strictly restricted to @cloudspace.goog and @google.com corporate identities.
  • Google OAuth Token Validation: Client-side Google Sign-In passes Bearer ID tokens, verified server-side via Google's token verification API.
  • Application Default Credentials (ADC): Seamless backend authentication with Google Vertex AI and Cloud Storage without exposing private keys.
  • Environment Fallback: Supports Google AI Studio API keys (GEMINI_API_KEY) for local testing and container development.
