1. 🎯 Executive Summary & Purpose

The Magic Countdown Generator is an enterprise generative video application designed to produce bespoke, photorealistic 30-second cinematic countdown videos (counting sequentially backwards from 10 down to 1).

The system tailors scenes dynamically to any customer, brand identity, or enterprise domain (e.g. Bundesdruckerei, Lufthansa Group, Infineon, Adidas, Porsche). Every countdown numeral is diegetic—physically fabricated inside the actual filmed environment (laser-etched identity chips, cockpit dials, stadium architecture, industrial machinery) with zero synthetic 2D overlay badges.

v12.0 Modernization: The pipeline has transitioned from legacy multi-frame image-to-video synthesis to Direct Veo 3.1 Text-to-Video synthesis. Users can export either the standalone 30.0s master or an Extended Master (+ Google I/O Outro) featuring an automated 2-second crossfade transition and cloud persistence.

3. ⏱️ Temporal Math & Video Transformation Logic

Google Veo 3.1 synthesizes raw video clips of exactly 4.000 seconds (240 frames @ 60fps). To match the musical slot requirements (2.300s in Act 1, 3.300s in Act 2), each clip undergoes deterministic temporal trimming:

A. Temporal Transformation Modes

  • TRUNCATE_FRONT (Default & Standard): Trims the opening seconds of the video, preserving the final seconds where the camera pushes in and locks onto the physical numeral in sharp macro focus.
    Formula: trimStart = 4.000 - targetDuration (Act 1: trim 0.0s–1.7s, keep 1.700s–4.000s; Act 2: trim 0.0s–0.7s, keep 0.700s–4.000s).
  • TRUNCATE_BACK: Preserves the beginning of the clip and trims the tail (ideal when the numeral reveal occurs upfront).
    Formula: trimStart = 0.000, duration = targetDuration.
  • SPEED_UP: Compresses the entire 4.0s motion smoothly into the target slot duration.
    Formula: setpts=(targetDuration / 4.000) * PTS.

B. Interactive Playhead Mapping Function (mapPlayheadToSlotTime)

When scrubbing the interactive 30-second waveform timeline in the UI, the global playhead time $T \in [0.0, 30.0]$ is translated in real-time into the active slot index, local video clip time, and dramatic silence state: 

if (T >= 9.200 && T < 10.200) {
  // Dramatic Pause: Render 100% Solid Black Screen, Zero Badge Overlays
  return { slotIndex: 0, localClipTime: 0.0, isDramaticPause: true };
} else if (T < 9.200) {
  // Act 1: Slots #10 down to #7 (Duration = 2.300s per slot)
  const slotIndex = 10 - Math.floor(T / 2.300);
  const slotOffset = T % 2.300;
  const localClipTime = (4.000 - 2.300) + slotOffset; // Starts at 1.700s in raw clip
  return { slotIndex, localClipTime, isDramaticPause: false };
} else {
  // Act 2: Slots #6 down to #1 (Duration = 3.300s per slot)
  const act2Time = T - 10.200;
  const slotIndex = 6 - Math.floor(act2Time / 3.300);
  const slotOffset = act2Time % 3.300;
  const localClipTime = (4.000 - 3.300) + slotOffset; // Starts at 0.700s in raw clip
  return { slotIndex: Math.max(1, slotIndex), localClipTime, isDramaticPause: false };
}

4. 🚀 Complete Step-by-Step Studio Workflow (v12.0)

Stage 1: Customer Theme & Enterprise Presets

User specifies the brand name (e.g. Bundesdruckerei, Lufthansa) and industry domain, or selects from curated enterprise presets. Gemini Search Grounding automatically extracts authentic visual motifs.

Stage 2: AI Diegetic Prompt Engineering

Gemini 3.8 Flash synthesizes 10 synchronized countdown prompts. Prompts follow front-loaded number focus and macro-environmental embedding rules. Users can tune the live system instructions via the in-app Veo 3 Prompt Guide editor.

Stage 3: Direct Veo 3.1 Text-to-Video Engine

Zero intermediate starting images. Google Veo 3.1 directly generates 4.0s high-fidelity cinematic motion clips straight from prompts. Supports both Veo 3.1 Fast (Turbo) and Veo 3.1 Quality with 1-click concurrent bulk dispatch.

Stage 4: Master Concat, Extended Outro & Cloud Persistence

Preview on the interactive waveform timeline. Choose between exporting a standalone 30s Countdown Master or an Extended Master (+ Google I/O Outro) with a 2-second crossfade transition. All master files are permanently saved to Google Cloud Storage.

5. ✨ Dual Master Export & Extended Outro Transition Architecture

Users can choose between two final deliverables directly from the bottom export banner:

🎬 30s Countdown Master

Concatenates the 10 temporally-trimmed countdown clips, inserts the 1.0s dramatic blackout pause at 9.20s, synchronizes the master soundtrack, and exports a broadcast-ready 30.0s 4K UHD video.

✨ Extended (+ Google I/O Outro)

Appends the keynote outro video (google-io.mp4, 93.2s) to the 30s master, creating a combined 121.2-second 4K master presentation with an automated 2-second crossfade transition.

Automated 2-Second Transition & Audio Mix Pipeline

  • Stream Normalization: Normalizes video timebases and framerates (settb=AVTB,fps=60) to eliminate FFmpeg timebase mismatch errors (code 234).
  • Video Fade Out (Video 1): The 30s countdown master dissolves into black across the final 2.0s via xfade=transition=fadeblack:duration=2.0:offset=28.0 before revealing the outro.
  • Soundtrack Fade Out (Video 1): The countdown background music track fades smoothly to complete silence via afade=t=out:st=28.0:d=2.0.
  • Full-Volume Outro Audio (Video 2): The Google I/O outro audio is delayed to start at 28.0s (adelay=28000|28000) and enters at 100% full volume with zero fade-in, guaranteeing the speaker's voiceover is immediately crisp and audible.
  • Normalized Mixing: Audio streams are blended cleanly via amix=inputs=2:duration=longest:weights=1 1:normalize=0.
ffmpeg -y \
  -i /app/output/master_countdown_10shots_4k.mp4 \
  -i /app/public/countdown/google-io.mp4 \
  -filter_complex "
    [0:v]settb=AVTB,fps=60[v0];
    [1:v]settb=AVTB,fps=60[v1];
    [v0][v1]xfade=transition=fadeblack:duration=2.00:offset=28.00[v];
    [0:a]aresample=44100,aformat=sample_fmts=fltp:channel_layouts=stereo,afade=t=out:st=28.00:d=2.00[a0];
    [1:a]aresample=44100,aformat=sample_fmts=fltp:channel_layouts=stereo,adelay=28000|28000[a1];
    [a0][a1]amix=inputs=2:duration=longest:weights=1 1:normalize=0[a]
  " \
  -map "[v]" -map "[a]" \
  -c:v libx264 -preset ultrafast -crf 18 -pix_fmt yuv420p \
  -c:a aac -b:a 320k -movflags +faststart \
  /app/output/countdown_extended_master_4k.mp4

7. 📝 Customizable Veo 3 Prompt Guide & Per-User Isolation

  • Per-User LocalStorage Isolation: Prompt engineering directives can be customized directly in the UI. Custom rules are saved in localStorage under veo_custom_prompt_guide, preventing any cross-user leakage.
  • Header Indicator: An active indicator badge appears in the header whenever personalized rules are active.
  • Payload Injection: Both prompt generation and prompt regeneration endpoints accept customPromptRules in the request payload, seamlessly applying user-specific directives during Gemini synthesis.

8. 🔒 Security, Authentication & Domain Gate

  • Authorized Domains Gate: Access to video/prompt generation endpoints is strictly restricted to @cloudspace.goog and @google.com corporate identities.
  • Google OAuth Token Validation: Client-side Google Sign-In passes Bearer ID tokens, verified server-side via Google's token verification API.
  • Application Default Credentials (ADC): Seamless backend authentication with Google Vertex AI and Cloud Storage without exposing private keys.
