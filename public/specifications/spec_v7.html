Elephant-Goldfish Model (EGM) Specification v7.0

Magic Countdown Generator Specification

30-Second Cinematic Countdown Generator with Gemini Nano Banana (gemini-2.5-flash-image) and Veo 3 Video Synthesis

1. Five-Stage Sequential Workflow Pipeline

In accordance with the Elephant-Goldfish Model (EGM), the user exercises strict verification gates before resource-intensive generation:

  • Stage 1 (Brand & Style Direction): Configure Customer Brand (e.g. Porsche Motorsport) and scene setting. Action: "Generate 10 Text Prompts".
  • Stage 2 (Human Verification & Prompt Review): Review all 10 diegetic prompt cards (10 down to 1). The user can manually edit prompts in-place, trigger "Re-create Prompt" for individual numbers with Gemini, or approve all prompts before proceeding. Action: "Create Veo 3 Input Images".
  • Stage 3 (Diegetic Image Synthesis): 2-worker bounded parallel pool synthesizes photorealistic 1024x1024 / 16:9 images with Gemini Nano Banana. Full-width stacked layout for maximum laptop screen resolution.
  • Stage 4 (Veo 3 Video Synthesis & Side-by-Side Inspection): Generates 4.0s dynamic camera zoom clips without audio (-an). Once generated, each card dynamically splits into 30% Input Frame / 70% Veo 3 Video.
  • Stage 5 (Temporal Alignment & Master Export): Interactive waveform timeline maps slots to the 30.0s master soundtrack and executes native FFmpeg concatenation.

2. AI Model Integration & APIs

gemini-2.5-flash

Prompt Director Engine

Synthesizes 10 creative diegetic prompt concepts and handles single-shot prompt re-creation via /api/recreate-prompt.

gemini-2.5-flash-image

Gemini Nano Banana

Generates photorealistic 16:9 images with physically embedded countdown numerals (10 to 1) directly in machine textures.

Google Veo 3

Image-to-Video Engine

4.0-second 60fps dynamic camera push-in zooms rendered without audio (-an, -preset ultrafast) for rapid rendering throughput.

FFmpeg Native Core

Master Soundtrack Muxing

Concatenates the 10 video clips and overlays the 30.0-second master audio track with exact millisecond synchronization.

3. Observability & Portal Architecture

  • Live Log Analysis: Real-time in-memory ring buffer tracking all Gemini AI requests, latency, image payload sizes (e.g. 1.66 MB PNG), and HTTP status codes via GET /api/logs.
  • React Portal Modals: All overlays (Log Analysis, Test Gemini API, Model Selector) are portaled to document.body at z-[99999] to prevent clipping or viewport occlusion.
  • 2-Worker Bounded Queue: Guarantees that neither image generation nor video rendering exceeds 2 concurrent tasks, preventing 429 quota errors.
