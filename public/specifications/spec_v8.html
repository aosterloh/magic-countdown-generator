1. Executive Summary & Core Philosophy

The Magic Countdown Generator is a specialized high-fidelity generative engine designed to produce broadcast-grade 30-second countdown teaser videos. Unlike traditional video editors that rely on artificial text overlays (which degrade production value), this system mandates 100% Diegetic Number Integration and Coordinated Camera Movement Reveals.

The Diegetic Mandate: Numbers 10 through 1 must exist exclusively as physical, tangible entities embedded within the visual geometry of the physical scene (e.g., laser-etched carbon fiber dials, titanium turbine markings, neon dashboard tachometers, stamped alloy brackets). Floating graphics, UI badges, and synthetic HUD overlays are strictly prohibited.
The Coordinated Reveal Strategy: In the initial static starting frame ($t=0$), the numeral is deliberately concealed behind scene objects, shadow occlusions, or optical depth-of-field. Over the course of the 4.0-second Veo 3 video clip, deliberate camera motion (push-in, parallax pan, rack focus) organically exposes and frames the diegetic number.

3. 5-Stage Human-in-the-Loop Pipeline

Stage 1 Customer Brand & Aesthetic Setting

User enters Brand Name (e.g., Porsche Motorsport), Creative Theme Context, and optional Style Modifiers. The Gemini 2.5 Flash Creative Director expands this into 10 cohesive narrative beats with coordinated starting frames and camera motions.

Stage 2 Prompt Review & Dual Concept Editing

Displays all 10 slots side-by-side with independent text editors for Starting Image Framing (Number Concealed) and Veo 3 Camera Motion (Number Revealed). Features 1-click individual Gemini prompt re-creation and global batch approval.

Stage 3 Parallel Image Synthesis & Approval Stream

Renders 10 photorealistic starting images using 2 parallel asynchronous worker queues. Includes a top rotating prompt carousel, dynamic Google progress bar, card-level refinement tools (Redo Shot, 2-Image Dual Ingestion Refine, Rollback N-1), and prominent dual "Approve All 10 Images" action buttons at both top and bottom.

Stage 4 Veo 3 Image-to-Video Synthesis (10 × 4.0s @ 60fps)

Synthesizes 4.0-second motion clips using Google Veo 3 / dynamic 60fps motion zoom without audio. Displays a responsive 30% static frame / 70% video player layout with individual playback controls.

Stage 5 Master Concat & Audio Sync Timeline

Interactive waveform editor displays all 10 slots with zoom and playhead scrubbing against the synchronized audio track. Final export compiles all clips with 1.0s linear crossfades and normalized EBU R128 stereo audio into a single broadcast master_countdown.mp4.

4. Application Security & Access Control

The system employs a streamlined, secure password gate that protects all generation endpoints without external OAuth redirect dependencies:

  • Environment Variable Configuration: Protected by APP_PASSWORD (default: ) configured in .env and GCP Cloud Run environment variables.
  • Endpoint Protection: POST /api/auth/password verifies submitted passwords with constant-time equality checks and returns an authenticated session token.
  • Header Cleanliness: UI removes unnecessary user profile clutter from the top-right header, focusing exclusively on theme controls and core creative workflow.
